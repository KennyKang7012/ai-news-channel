## 一、語言與用字規則

**變體：** 繁體中文，**臺灣用語**。不是香港用語，也**不是**大陸用語或簡體字直接轉繁。

**禁用大陸／簡體慣用詞，一律改用臺灣慣用詞：**

| 禁用（大陸用語） | 改用（臺灣用語） |
|---|---|
| 人工智能 | 人工智慧 |
| 信息 | 資訊 |
| 网络／网路 | 網路 |
| 视频 | 影片 |
| 软件／硬件 | 軟體／硬體 |
| 程序（作 program 解） | 程式 |
| 数据 | 資料／數據（依語境） |
| 算法 | 演算法 |
| 优化 | 最佳化 |
| 监管部门 | 主管機關 |

**標點與格式：**
- 全形標點貫穿全文（，。、；：「」），書名／法規名用《》
- 數字、拉丁字母術語、URL 用半形，緊鄰中文字時前後留半形空格（例：「第 50 條」「EU AI Act 於」）
- 日期一律寫作 `2026 年 8 月 2 日`，禁止 `8/2`、禁止 `二〇二六年`

**首次出現中英對照規則（credibility requirement，非裝飾）：** 每個專有名詞、法規名、機構名、法律術語第一次出現時寫成 `中文譯名(English original)`，之後只用中文。讀者必須能夠對照回英文原始來源。

> **範圍待釐清（cycle #001 Supervisor 發現的落差）：** 這條規則在 cycle #001 只有 `article.md` 確實套用，4 則社群貼文和電子報都沒有。CTO brief 原文寫「governs every deliverable」，但 Supervisor 的正式驗收清單並未把它列為跨平台的硬性檢查項。**下一輪循環前，CTO 應明確裁示：此規則是否適用所有交付物，還是僅限文章本身**，並在裁示後更新本文件、拿掉這段待釐清備註。

## 二、語氣規則（正式、克制、具權威感）

- 以嚴肅產業媒體的語氣書寫，讀者是「產品主管、法務、創辦人」等具備專業知識的成年人，不是初學者
- 第二人稱僅限「若貴公司將 AI 系統投放至歐盟市場」這類特定的營運者語境，優先用「貴公司／業者／開發者」而非裸的「你」
- 克制才是語氣訊號，不是靠敬語或公文腔堆疊出來的正式感——讀起來應該像嚴肅的產業媒體，不是政府公告或新聞稿

**全平台禁用（含 Threads、Instagram）：**
- 句尾語助詞：啦、囉、欸、喔、耶、嘛、唷
- 網路流行語、顏文字
- 誇大／標題黨詞彙：顛覆、革命性、劃時代、震撼、炸裂、神器、王炸、一切都變了、時代來臨、大爆發、必看、懶人包、一次搞懂、超狂、驚人、史上最強、你不可不知
- 修辭填充語：「說真的」「不誇張」「你沒看錯」「別再…了」「快來」
- 表情符號（全平台，含 Twitter/X 與 Instagram）
- 驚嘆號（引號內除外）
- Instagram 常見的裝飾性分隔符號：▬▬、✦、•••、＿＿
- 假性精確／編輯立場詞：「恐將」「勢必」「無疑」——法律狀態不確定時，應寫「截至 [日期]」並附時間戳，而非斷言

## 四、CJK 字數換算表（各平台）

英文字數規格（CLAUDE.md：文章 800–1,200 字、電子報 180–250 字）換算成中文字數時，採用 **≈1.75 中文字／英文字** 的比例（PM 於 cycle #001 rev-3 確認接受，現為 zh-TW 循環的固定標準）。

| 平台 | 平台上限 | CJK 計數方式 | 實務中文字預算 |
|---|---|---|---|
| 文章（article.md） | 對應英文 800–1,200 字 | — | 目標 **1,600 中文字**，硬性範圍 **1,400–2,100 中文字**（不含標點、空白、英文括註） |
| Twitter/X | 280（加權） | **CJK 每字計 2**；連結固定佔 23 | (280 − 23) ÷ 2 ≈ 128 中文字 → 建議 ≤ 120 中文字，單則不開串 |
| LinkedIn | 1,300 字元 | 每字計 1 | ≤ 1,300；目標 **500–700 中文字**；條列間用換行；末端 ≤3 個標籤 |
| Threads | 500 字元 | 每字計 1 | ≤ 500；目標 **300–400 中文字**；不加標籤 |
| Instagram | 2,200 字元 | 每字計 1；標籤計入 | ≤ 2,200；目標 **350–600 中文字（含標籤）**；鉤子句 ≤40 中文字（動態牆約 125 字元即截斷）；≤8 個標籤；Alt text 另計、不算入字數 |
| 電子報（newsletter.md） | — | — | **320–450 中文字**，純文字相容，單一連結 |

各交付物的 front matter／標題行應同時記錄實際中文字數與約略對應的英文字數，方便跨規格稽核。若超出預算，優先刪減次要子句，**絕不刪除具引用價值的具體事實（明確義務名稱或確切數字）**。

## 五、Instagram 圖文分工規格（cycle #001 新增，現為標準規格）

Instagram 貼文與圖卡（image card）**成對發布**，是四則社群貼文中唯一以視覺為主體者：

- **與圖卡的分工（硬性）：** 圖卡承載「日期與事件」等核心視覺資訊；文案承載「內容與判斷」等實質內容。**文案第一句不得與圖卡覆蓋文字逐字重複。**
- **首行即為全部：** Instagram 動態牆僅顯示前約 125 個字元即截斷。開頭必須是一句可獨立成立、具資訊量的**鉤子句（≤40 中文字）**，自帶時間錨點與一項具體事實。禁止用問句、寒暄或「你知道嗎」式開場浪費首行。
- **結構（依序，以空行分段）：**
  1. 鉤子句 — 單行，≤40 中文字，含時間錨點 + 一項可查證事實
  2. 脈絡段 — 2–3 個短段落，共約 200–350 中文字
  3. CTA — 一至兩句，語氣克制，不使用「快點」「別錯過」等催促語
  4. 連結說明 — Instagram 內文連結不可點擊，須明確標示「連結見個人簡介(link in bio)」並附 `[LINK]` 佔位符；不得在內文貼出裸露長網址
  5. 標籤區 — 與正文分隔，置於最末，最多 8 個，計入 2,200 字元上限
- **Alt text（無障礙，必附）：** 另附 60–100 中文字的圖片替代文字，客觀描述圖卡構圖與其上文字，不作行銷語；獨立標記輸出，不計入 caption 字元數
- **禁止事項：** 不得重述整篇文章；不得出現引註編號 `[1]`（社群貼文一律以「來源見文章」處理）；不得暗示為法律或專業意見

## 六、跨平台通則

- **無重複開頭：** 四則社群貼文各自用不同開場、帶出不同的具體事實；Instagram 的鉤子句不得重複 Twitter/X 開場句或圖卡覆蓋文字
- **引註編號僅限文章：** `[1]`、`[2]` 等引註編號只出現在 `article.md`，社群貼文與電子報一律用「來源見文章」表示
- **翻譯完整性：** 交付物是「從英文 Researcher findings 直接寫成中文」，不是先寫英文草稿再機器翻譯；引述原文須註記原文（例：「…」(原文:"…")）
- **法規原文無官方中文版：** 描述法規內容時寫「依第 X 條規定」並附引註，不得將中文譯文當作具權威性的法規原文本身；文章需一次性聲明中文譯文為本刊自行翻譯
